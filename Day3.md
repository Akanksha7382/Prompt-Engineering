# 1. Introduction

In the previous two days, we learned:

### Day 1 - Be Specific

Tell the AI exactly what you want.

### Day 2 - Give Context

Give the AI the relevant background information it needs.

Today we will learn another important Prompt Engineering technique:

> **Give Examples**

Instead of only telling the AI what to do, we can show the AI examples of the input and the output we expect.

This technique is commonly called:

> **Few-Shot Prompting**

---

# 2. What is Few-Shot Prompting?

Few-shot prompting means providing a small number of examples in the prompt so that the AI can understand the pattern we want it to follow.

Simple structure:

```text
Example 1
Input → Output

Example 2
Input → Output

Example 3
Input → Output
