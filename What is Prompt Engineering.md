1. What is Prompt Engineering?

Prompt Engineering is the process of designing and improving instructions given to an AI model so that you get a better and more useful response.

❌ Bad prompt
Simple example:
```
Explain Python.
```

AI doesn't know:

Your knowledge level
What exactly you want
How much detail you need
Whether you want examples
Whether you want interview preparation


✅ Better prompt
```
You are a Python instructor.

Explain Python functions to a beginner.

Cover:
1. What is a function?
2. Why do we use functions?
3. Function syntax
4. Parameters and return values
5. One simple example
```
Use simple language and explain the code line by line.

Now the AI has much more information.

That's the basic idea of Prompt Engineering.
