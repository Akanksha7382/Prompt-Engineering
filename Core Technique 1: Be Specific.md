# Core Technique 1: Be Specific

## Definition

Be specific means providing clear instructions,
context, requirements, constraints, tone, and
expected output format so that the AI model does
not need to guess the user's intention.

## Main Components

1. Role
2. Task
3. Context
4. Audience
5. Tone
6. Format
7. Constraints

## Key Principle

The more clearly the desired result is defined,
the less ambiguity the model has when generating
the response.

## Don't Make the Model Guess" — The Key Idea

Think about it like giving instructions to a new employee.

Suppose you tell an employee:
```
"Prepare a report."
```

They will ask:
- Which report?
- For whom?
- What information?
- How many pages?
- What format?
- By when?
- qqWhat level of detail?

AI works similarly.

Instead of:
```
Prepare a report.
```

You could say:
```
Prepare a 2-page project status report
for the development manager.

Include:
- Completed work
- Current work
- Blockers
- Next steps

Use a professional tone.

Format the report with headings and bullet points.
```
Now there is much less ambiguity.

## A Simple Formula to Remember 🧠

For your notes, remember this:
```
BE SPECIFIC

        ↓

WHO?
Role / Audience

        ↓

WHAT?
Task

        ↓

WHY / BACKGROUND?
Context

        ↓

HOW?
Tone / Style

        ↓

WHAT SHOULD IT LOOK LIKE?
Format

        ↓

WHAT ARE THE RULES?
Constraints
```
